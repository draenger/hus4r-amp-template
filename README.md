# HUS-4R – AMP template

AMP (CubeCoders) application template for the HUS-4R dedicated server.
Add `draenger/hus4r-amp-template:main` in AMP: Configuration → Instance Deployment → Configuration Repositories, then Fetch.

This repository contains only template configuration. No game files, no download links, no credentials:
the download address and login are entered per instance in the AMP settings.
